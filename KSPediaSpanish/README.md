# KSPedia de Koffee en español

Esta edición anterior se descarga desde la release v0.1.2: https://github.com/Shodrem/Koffee-KSP-Mod/releases/tag/v0.1.2. No está actualizada para v0.1.3. El bundle compilado se distribuye como asset de release y se ha retirado del repositorio de fuentes.


Guía opcional de 16 páginas. Esta carpeta se distribuye fuera de GameData para que puedas elegir el idioma.

Con KSP cerrado, copia `kspedia_koffee.ksp` en `GameData/ShoAerospace/Koffee/KSPedia/` de tu instalación de KSP y acepta sustituir el archivo del mismo nombre.

Instala una sola edición. No conserves una segunda copia `.ksp` con otro nombre: sus identificadores de páginas son los mismos. Para volver al inglés, restaura el archivo de la distribución principal.

La selección es manual; cambiar el idioma de KSP no sustituye este archivo. No requiere otro plugin. Reinicia KSP después del cambio.

Las licencias y la atribución se incluyen en esta carpeta. Recursos originales de Koffee: shodrem (SHO Aerospace), CC BY-NC 4.0.

## English

Optional 16-page Spanish guide. With KSP closed, copy `kspedia_koffee.ksp` into your KSP installation's `GameData/ShoAerospace/Koffee/KSPedia/` folder, replacing the existing file.

Install one edition only. Do not keep a renamed second `.ksp` copy: page identifiers are shared. Restore the main distribution's file to return to English. Selection is manual and requires a game restart; no additional plugin is needed.

Licenses and attribution are included. Original Koffee assets: shodrem (SHO Aerospace), CC BY-NC 4.0.
