# Laboratorio avanzado AL-25

Exterior vigente: acabado Limpio o Aislamiento térmico (predeterminado), ocho peldaños superiores y triggers Ladder. [Exportación y validación](../../../../../Meshes/AdvancedLab_25_Basic/Exportacion-Exterior-Actual.md).

Acabado adicional del cilindro: **Metal cepillado**, con juntas, tornillos y nervaduras en el mapa de normales. [Texturas y comprobaciones](../../../../../Meshes/AdvancedLab_25_Basic/Exterior-BrushedMetal-v1.md). Añadido al CFG e instalado en `D:/Juegos/KSP`; pendiente de prueba visual en KSP.

Pieza de producción de SHO Aerospace, con IVA de dos plazas y soporte para los experimentos actuales de Koffee (`ModuleKoffeeLab`, `StationBasic`). Requiere contenedores de experimento y un Experiment Manager separado. La capacidad específica para experimentos avanzados se añadirá en el futuro.

Categoría Ciencia; compra 6500 fondos, desbloqueo 16000 fondos, masa 3 t, batería 100 EC. Sin conversión stock de datos en ciencia adicional ni función de mando. Tecnología base `advExploration`; con el extra de árbol propio, `koffeeAdvancedHardware` después de Hardware, por 160 de ciencia.

El ID `SHOAdvancedLab25Test`, las rutas y las claves de localización se conservan por compatibilidad. El nombre visible es definitivo. No duplicar ni renombrar los recursos para retirar el sufijo interno `Test`.

Ficha, balance inicial y límites de validación: [AL25-Laboratorio-Definitivo.md](../../../../../docs/AL25-Laboratorio-Definitivo.md). Modelado y exportación: [Estado-IVA-AdvancedLab25.md](../../../../../docs/Estado-IVA-AdvancedLab25.md).
