Koffee v0.1.8 for Kerbal Space Program 1.12.5

Close KSP before installing. For an upgrade, remove the previous
GameData/ShoAerospace/Koffee folder first, then copy the GameData folder from this
ZIP into your KSP directory. Keep your saves. A clean replacement removes retired
configuration files and models; overwriting alone can leave duplicate parts.

Install ModuleManager and HarmonyKSP separately. Optional integrations:
Background Resource Processing (BRP) 0.3.4 (should work with later versions),
Dynamic Battery Storage, Contract Configurator,
SystemHeat and Lonapse. Their DLLs are not included. Koffee.BRP.dll is rebuilt
against BRP 0.3.4; later versions have not been tested.

The package includes Koffee.dll, Koffee.BRP.dll and KoffeeContracts.dll, the runtime
configuration, models, textures, icons, Lonapse dialogue data and the current
24-page English KSPedia. The older Spanish guide is not updated for this version.
